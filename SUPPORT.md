# Support

Need help with **AI Gateway API**? Here's where to look:

- 📖 **Documentation** — start with the [README](README.md) and
  [ARCHITECTURE](docs/ARCHITECTURE.md).
- 🔌 **API reference** — run the project and open `http://localhost:3000/docs`
  (Swagger UI).
- 🐛 **Found a bug?** — open a [bug report](https://github.com/DiegoBrantes/ai-gateway-api/issues/new/choose).
- 💡 **Have an idea?** — open a feature request.
- 🔒 **Security issue?** — please follow [SECURITY.md](SECURITY.md) instead of a
  public issue.

For general questions, open a GitHub Discussion or issue. Please avoid sharing
real API keys or secrets in any public thread.
